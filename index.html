Maplefind

A web app that matches a Bangladeshi student's results to Canadian university courses. Enter a GPA or CGPA and an IELTS or PTE score, and it checks them against each course's published entry rules to show where you can apply.

What I did

  • Planned the product, the pricing and the data model.
  • Researched and keep up the course data that powers it.
  • Designed every page in Maplefind's own brand.
  • Built and shipped it with AI coding tools, reviewing each change as a GitHub pull request with a Vercel preview before merging.

What it does

  • Matches a student profile to courses in seconds.
  • Course pages with entry rules, fees, deadlines and work permits.
  • Compare up to four courses and export a PDF shortlist.
  • Student passes paid by bKash, and agency accounts.

Data you can trust

The course list lives in a Google Sheet. A script syncs it to the database every six hours and stops itself if the incoming data looks wrong, so a bad edit never reaches students.

Access is enforced in the database, not the browser: free accounts see the basics, and full course details open only with an active pass.
